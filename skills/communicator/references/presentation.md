# Presentation mode

Purpose: slides that carry one clear argument, with evidence, readable in seconds. Words and storyline only; visual styling follows `resources/taste/DESIGN-SYSTEM.md` and whichever deck tool Frederik picked (ask before picking one for a client deck).

## Storyline first

1. Write the governing message of the deck in one sentence.
2. Write every slide title as a full-sentence claim (action title). Read the titles alone: they must tell the whole story in order. Use an arc from [storyline](storyline.md); SCQA is the usual opening.
3. Give each slide one job: set up the problem, show evidence, explain a mechanism, compare options, or ask for a decision. If a slide needs two titles, split it.
4. Only then build each slide body to prove its title.
5. Check transitions: "Because of X, we should Y" beats a list of topics.

## Slide rules

- **Action titles:** "Personalised offers lifted conversion 18% in the pilot", not "Pilot results".
- **The body proves the title:** a chart, table, diagram or a few short points. Anything else moves to notes or the appendix.
- **No fixed word quotas.** A pre-read deck can carry more text than a talk deck. Never fix crowding by shrinking the font.
- **Label units, baseline, period, source** where they matter.
- **Highlight the one thing to notice.**

## Charts (graphical integrity, after Tufte)

| Question | Chart | Check |
|---|---|---|
| Change over time | Line | Interval, gaps, definition changes |
| Compare categories | Bar or dot | Bars start at zero |
| Before and after | Slope or paired values | Comparable cohorts and periods |
| Part of a whole | Stacked bar or table | Denominator stated; few categories |
| Relationship | Scatter | Do not imply causation |
| Process | Flow diagram | Failure paths shown |

Label data directly instead of legends. No 3D, gradients or decoration. Put the takeaway in the title and annotate the point that matters. For anything chart-heavy, also use the `dataviz` skill.

Tufte himself criticised bullet-outline slides; for dense analytical content, recommend a written document as the main vehicle with slides as support. Action titles and one message per slide are consulting practice, not Tufte.

## Output format for slide content

For each slide: **Title** (action title), **Body** (evidence), **Visual** (type and what to highlight), **Notes** (what the speaker says, plus detail removed from the slide).

## Common failures

- Topic titles ("Background", "Results").
- Bullet walls pasted from a document.
- Several messages on one slide.
- The conclusion appears only on the last slide.
- A caveat in tiny text that reverses the claim.
